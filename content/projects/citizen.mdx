## What it is

Citizen is a life-simulation game set across five blockchain-themed cities: Ethereum, Solana, Base, BNB Chain and Avalanche. Each player joins one city. The long-term aim is a game about everyday virtual life rather than a single competition.

## How I am building it

I build Citizen in stages, one feature at a time, testing and deploying each stage before starting the next. Gameplay follows a daily timeline that starts at home in the morning and moves through the day. Code is managed on GitHub and deployed on Vercel.

## What it shows

Planning a larger product, breaking it into deliverable stages and shipping working increments.

## Status

Version 0.9 is live at citizen-liart.vercel.app and still in development.
