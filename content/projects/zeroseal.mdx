## What it is

ZeroSeal is a personal prototype for security disclosure on a blockchain. It runs on the Stellar Testnet, not the main network, and it is a hobby project rather than a production service.

## What I worked on

I built the application in Next.js, React and Tailwind CSS. My work included a multi-step claim wizard, a guided proof demonstration and a verification layer, alongside several design passes on the interface. Features that are planned rather than built are labelled as planned on the site itself.

## What it shows

Building and shipping a working web application end to end, and presenting security-related functionality to non-specialist users clearly.

## Status

Live on testnet at zeroseal.vercel.app. It has no production users or audits, and it does not handle real funds.
